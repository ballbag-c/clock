# Clock

A full-screen bedside clock for Emily's iPad mini.

- **Daytime:** time, day and date
- **Bedtime soon** (amber): 30 minutes before bedtime
- **Sleepy time** (dim red): bedtime until wake-up, says when she can get up
- **Get up** (green): for an hour from wake-up time

Defaults: bedtime 7:30 pm, school-day wake-up 7:15 am, weekend wake-up 7:30 am.
Hold the faint gear in the bottom-right corner for a second to change them.
Settings are saved on the iPad itself.

Live at https://ballbag-c.github.io/clock/
